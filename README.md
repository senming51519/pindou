# 拼豆配对

一款支持微信小游戏和抖音小游戏的拼豆整理游戏。玩家需要在限时内移动不同颜色的拼豆，将它们放回图案中的正确位置并完成关卡。

## 当前功能

### 核心玩法

- 默认提供 108 个拼豆图案关卡。
- 每关随机打乱拼豆颜色，支持同色连续区域批量移动。
- 支持暂存区存放、移动和交换拼豆。
- 支持撤销上一步操作。
- 拼豆移动带有动画和音效。
- 自动适配不同尺寸的图案网格。

### 关卡与计时

- 每局限时 3 分钟，首次移动后开始计时。
- 通关后自动记录完成状态，并可进入下一关。
- 自动保存当前关卡，重新进入时恢复上次进度。
- 每天提供 10 点体力；开始挑战消耗 1 点，正常通关返还本局体力。
- 中途退出或挑战失败不返还体力，每日零点自动恢复。

### 道具系统

- **U 型磁铁**：随机选择一种颜色，最多自动整理 20 个拼豆。
- **刷子**：将暂存区中的拼豆自动归位。
- **冻结**：暂停倒计时 180 秒。
- 每局开始时三个道具各有 1 次基础使用次数。
- 磁铁、刷子和冻结每天都可分别签到领取 `+1`，次日自动重置领取状态。
- 已预留激励视频广告逻辑，开通流量主并配置广告位后可切换。

### 图鉴与设置

- 通关后自动解锁对应图案。
- 图鉴页面显示解锁数量，并支持查看图案大图、名称和关卡编号。
- 支持 `0.8x–3.5x` 画布缩放，放大后可拖动查看大型图案。
- 支持背景音乐和操作音效开关，设置保存在本地。
- 包含加载页、主页、游戏页、图鉴页和设置弹窗。

### 关卡管理

- 支持内置关卡和随包发布的 `published_levels.json`。
- 支持从本地存储加载和热更新自定义关卡数据。
- PC 管理页面支持上传图片、生成拼豆图案、添加关卡、导出和发布关卡 JSON。

## 平台支持

- 微信小游戏：`wechat-game/`
- 抖音小游戏：`douyin-game/`
- 共享核心逻辑：`shared-game-core.js`
- PC 关卡管理工具：`index.html`

两个小游戏版本共用核心代码，并分别配置平台 API 与动画参数。运行 `copy-core.bat` 可将共享核心同步到两个平台目录。

## 当前数据与限制

- 游戏进度、体力、设置和每日领取状态保存在设备本地。
- 当前未接入账号登录、云端存档、排行榜、好友系统或支付。
- 激励视频广告默认关闭，正式启用前需要配置平台广告位 ID。
